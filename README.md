# Restaurant Management System
A full-stack application built with **.NET Core API** and **Angular**.

## Features
* CRUD operations for Menu Items.
* Order tracking and Revenue calculation.
* SQL Server integration.

## How to Run
1. Run the `script.sql` in your SQL Server.
2. Update `appsettings.json` with your connection string.
3. Run `dotnet run` in the Api folder.
